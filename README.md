# Deutch

 Kopf oder Zahl (C#)

Ein einfaches konsolenbasiertes Münzwurfspiel (Kopf oder Zahl).

 Wie wird es ausgeführt?
1. Öffnen Sie das Projekt auf Ihrem Computer.
